# 第二期开发需求

## 项目背景

- 项目路径：D:\Projects\sup-ai-coach
- 已完成第一期：路由、学生身份、Supabase 5 张表、主布局、首页课程地图、模块 4（现有 AI 评分）

## 任务 1：生成图片映射表

新建 `src/data/images.ts`，导出对象，key 是教材图号（如 `"图2-1-1"`），value 是路径（如 `"/images/raw/fig2-1-1.png"`）。
规则：图号里的"图"换成"fig"，如 `图2-1-1` → `fig2-1-1.png`。
把 `public/images/raw/` 下所有图片都映射进去。

```ts

  images?: { src: string; caption: string }[];
  subsections?: ContentSection[];

export const module1Content: ContentSection[] = [...]

分节：

1.1 桨板的分类（按结构、按场景）

1.2 桨板的结构（板首、板尾、甲板、板底、侧边、曲度、脚垫、尾鳍、通气口、把手）

1.3 桨板的性能（10 项）

1.4 桨板配件

1.5 选桨、调桨与握桨

1.6 持板与搬运

教材里"图X-X"的引用要从 images.ts 取图，放进 images 数组。表格用 HTML 表格渲染，不做成图片。
```
