# 绕标画图题 Demo 需求

## 目标
在网站新增一个页面，测试"学生在桨板俯视图上画桨法轨迹"的交互可行性。
这只是 demo，验证交互和判定，不做正式集成。

## 页面位置
新建 `/demo/turn-drawing`，独立页面，不加入主导航，只能直接输地址访问。

## 页面结构

### 顶部
- 标题："绕标画图题 Demo"
- 题干："请画出左转弯时使用的两种桨法。用鼠标或手指在图上拖动画线。"

### 中间：画布区
- 一张桨板俯视图（SVG 或 Canvas 绘制，不用真实图片）
  - 长方形，纵向放置
  - 上方标注"板首"，下方标注"板尾"
  - 中间标注"站立区"
  - 左右两侧各画一条纵向分界线，把板分成"左侧""中间""右侧"三个区域
- 画布尺寸：宽 400px，高 600px（手机竖屏友好）
- 支持鼠标和触摸画线

### 交互
- 学生在画布上拖动画线，线是实线，颜色 #0066cc
- 画完一条线松手，自动保存为"第一条线"
- 再画第二条线，保存为"第二条线"
- 最多画两条线，画完两条后禁止再画
- 有"清除"按钮，清空所有线，重新画
- 有"提交"按钮，提交后判定

### 判定逻辑（宽松）
学生画完两条线后点提交，系统判定：

**第一条线**：如果线的主要部分在右半边，且起点 y 坐标在上半部（板首方向）、终点 y 坐标在下半部（板尾方向），判定为"前扫桨" ✓

**第二条线**：如果线的主要部分在左半边，且起点 y 坐标在下半部（板尾方向）、终点 y 坐标在上半部（板首方向），判定为"反扫桨" ✓

两条都判对，显示"完全正确！"
只对一条，显示"部分正确，再想想另一条"
都不对，显示"再试一次"

### 判定结果展示
- 提交后，页面底部显示结果
- 对的那条线变绿色，错的那条变红色
- 旁边显示"✓ 前扫桨" 或 "✗ 方向不对"

### 底部
- 显示标准答案示意图（一个静态的 SVG，标注两条正确轨迹）

## 技术实现
- React + TypeScript
- 用 SVG 或 Canvas 绘制（你决定哪个简单用哪个）
- 画线轨迹用数组存储 `{x, y}[]`
- 判定用简单的几何判断（点的位置、区域）
