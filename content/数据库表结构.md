# 数据库表结构

Supabase 共 8 张表，全部由 anon key 读写。

## students
- id: uuid, 主键, default gen_random_uuid()
- student_no: text, 唯一, 非空（学号）
- name: text, 非空
- class_name: text, 可空（班级，第三期新增）
- created_at: timestamptz, default now()
- last_seen_at: timestamptz, default now()

## module_progress
- id: uuid, 主键
- student_id: uuid, 外键 -> students(id)
- module_no: int, 1-4
- status: text, 'not_started' | 'in_progress' | 'completed'
- updated_at: timestamptz, default now()
- 唯一约束 (student_id, module_no)，更新用 upsert

## quiz_scores
- id: uuid, 主键
- student_id: uuid, 外键
- module_no: int
- score: int
- total: int
- answers: jsonb, 形如 [{q, selected, correct}]
- created_at: timestamptz, default now()

## practice_scores
- id: uuid, 主键
- student_id: uuid, 外键
- posture_score: int（姿态分）
- paddle_score: int（桨法分）
- duration_sec: int
- detail: jsonb
- created_at: timestamptz, default now()

## page_views
- id: uuid, 主键
- student_id: uuid, 外键
- page_path: text, 非空
- viewed_at: timestamptz, default now()   ← 注意是 viewed_at，不是 created_at

## forum_posts（第三期新增 · 答疑园地帖子）
- id: uuid, 主键
- student_id: uuid, 外键 -> students(id)
- title: text, 非空
- content: text, 非空
- category: text, 非空（器材装备/安全知识/技术划行/其他）
- created_at: timestamptz, default now()

## forum_replies（第三期新增 · 答疑园地回复）
- id: uuid, 主键
- post_id: uuid, 外键 -> forum_posts(id)
- student_id: uuid, 外键 -> students(id)
- content: text, 非空
- created_at: timestamptz, default now()

## video_watches（第二阶段新增 · 视频观看记录）
- id: uuid, 主键
- student_id: uuid, 外键 -> students(id)
- video_id: text, 非空（B 站 BV 号）
- created_at: timestamptz, default now()
- 唯一约束 (student_id, video_id)

## RLS

所有表都有 RLS 策略 `for all using (true) with check (true)`，anon key 可读写全部数据。
